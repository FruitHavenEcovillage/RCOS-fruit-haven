## Decision Type Definitions

- **Operational** — Day-to-day functioning within existing rules
- **Strategic** — Long-term direction, significant resource allocation, creation/removal of major structures
- **Constitutional** — Changes to Layer 0 invariants, purpose, scope, or the governance system itself

> If a decision cannot be clearly classified, it defaults to the higher-impact type.
